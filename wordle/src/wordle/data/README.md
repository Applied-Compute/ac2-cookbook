# Dictionary source

`words.txt` contains the 8,636 five-letter ASCII entries from the public-domain
ENABLE lexicon, compiled by M. Cooper and Alan Beale. Entries are uppercase,
deduplicated, and sorted. This clone uses ENABLE for both guesses and answers.

Source: [dolph/dictionary's ENABLE mirror](https://github.com/dolph/dictionary/blob/master/enable1.txt),
retrieved September 7, 2026. [Public-domain notice](https://sources.debian.org/src/scowl/2018.04.16-1/Copyright).
